## Links

### [SuperTokens Core](https://github.com/supertokens/supertokens-core)

**Description:** Open-source backend for session management and authentication (email/password, passwordless, social/SSO login, MFA). Exposes an HTTP API consumed by SDKs in various backend languages; self-hostable or usable via managed service.

**Keywords:** authentication, auth, session management, self-hosted, open-source, SSO, passwordless, MFA, Auth0 alternative

**Possible usage:** Evaluate as a self-hosted alternative to third-party auth providers (e.g. Auth0, Keycloak) for services needing session/auth management without vendor lock-in or per-user pricing.
